# The full spread of search possibilities — 58 phrases, checked and handled

*Built 9 September 2026. Every category was checked against live search results
before being placed — 20 individual searches this session confirmed real
competitors, real umbrella terms, or real mismatches. The rest are the natural
siblings of a checked category (marked "same pattern"), not separate guesses.*

**How each row is handled — four honest outcomes, not fifty new pages:**
- **Own page** — an existing `/tools/*` page targets it directly.
- **Widened** — folded into an existing page's wording as a real synonym.
- **Hub** — the `/tools` index page's title/description carries it as an umbrella term.
- **Not targeted** — checked, and deliberately left alone, with the reason.

Building a new page per row would be keyword cannibalisation — two of our own
pages competing for the same search and both losing. That's why most rows
point at one of the ten existing pages, not a new one.

## What this means in practice

**Every real, matching term now lives inside an existing page's wording** —
the ten `/tools` pages plus the hub — rather than as 50 separate URLs
competing with each other. That was the actual design decision underneath
the whole list: breadth in *wording*, not breadth in *page count*.

**Three categories are deliberately left alone**, and each is now written
down so nobody chases them by accident later: exam conduct/proctoring, fee
management, and classroom hardware. All three are real, sizeable markets —
none of them is what Paperhint does.

**Ranking for any of these is Google's decision, not a switch we flip.**
What's done is discoverability and honest intent-matching. What happens next
depends on indexing (in progress — see the Search Console work), real usage,
and genuine citations elsewhere (Phase 3 of the earlier checklist).
